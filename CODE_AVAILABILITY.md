# Code Availability

This repository is the code-only companion package for the colloid focusing simulations. It contains source code, run scripts, validation scripts, configuration files, and the C particle-tracking kernel source.

It does not contain manuscript files or generated simulation outputs. Large generated artifacts should be archived separately, for example in Zenodo, HydroShare, an institutional repository, or a private review archive. The code expects regenerated or downloaded outputs to live under `outputs/`.

Suggested archive split:

- GitHub: source code, configs, tests, and documentation.
- Data archive: flow rasters, OpenFOAM outputs, trajectory libraries, generated CSV summaries, and final figures if desired.

Repository and reuse:

- Code repository: https://github.com/diogobolster/Colloid-Markov-Focusing
- Code license: MIT License, https://opensource.org/license/mit
- Data archive DOI: to be added when the generated simulation products are deposited.
